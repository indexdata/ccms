==== create filter

Define a new filter

[source,subs="verbatim,quotes"]
----
create filter `*_filter_name_*`
    where `*_search_condition_*`
----

[discrete]
===== Description

The `create filter` command defines criteria for selecting objects.
These criteria can then be used for querying sets via the `filter()`
operator.

[discrete]
===== Parameters

[frame=none,grid=none,cols="1,2"]
|===
|`*_filter_name_*`
|The name of the new filter, prefixed with the project name and a dot
 (`.`).  For example, a filter `f` in project `p` would be written as
 `p.f`.
|===

[discrete]
====== where

The `where` clause specifies a search condition in the form of a
Boolean expression.  Only objects that satisfy this condition will be
selected.

See also *Reference > Queries*.

[discrete]
===== Examples

To filter on records where decision = true:

----
create filter p.decided where decision = true;

select * from p.s where filter(p.decided);
----
