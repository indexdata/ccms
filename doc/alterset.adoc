==== alter set

Change the definition of a set

[source,subs="verbatim,quotes"]
----
alter set `*_set_name_*`
    alter property `*_property_name_*` set `*_value_*`
----

[discrete]
===== Description

The `alter set` command changes the definition of a set.

The `alter property` clause changes a property in the set's metadata.

[discrete]
===== Parameters

[frame=none,grid=none,cols="1,2"]
|===
|`*_set_name_*`
|The name of the set.

|`*_property_name_*`
|The name of the property in the set metadata.

|`*_value_*`
|The value of a single-value property.
|===

[discrete]
===== Properties

[%header,width=75%,cols="3,3,10"]
|===
|Property
|Type
|Value

|`name`
|single-value
|identifier

|`title`
|single-value
|text
|===

[discrete]
===== Examples

Set the title of set `s` to `Main Set`:

----
alter set s alter property title set 'Main Set';
----
